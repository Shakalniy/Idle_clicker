# Публикация игры в Telegram Mini Apps (TMA)

Пошаговый гайд: от сборки `dist/` до работающего мини-приложения с рекламой Adsgram.

---

## 1. Требования

- **HTTPS-хостинг.** Telegram открывает мини-апп внутри webview и требует валидный HTTPS-URL. `http://` и самоподписанные сертификаты не подойдут.
- Билд — это статика (`index.html` + JS + ассеты), серверной части не нужно.
- Аккаунт в Telegram для @BotFather, аккаунт на [adsgram.ai](https://adsgram.ai) — для рекламы.

## 2. Сборка

```bash
npm run build:tma
```

Результат — папка `dist/`. В `index.html` автоматически подключаются:

- `telegram-web-app.js` — официальный JS-мост Telegram;
- `adsgram master.js` — рекламная сеть (активируется при заданном blockId).

Для локальной проверки UI (вне Telegram работает режим эмуляции — реклама «показывается» мгновенно, сейвы в localStorage):

```bash
npm run dev:tma
```

## 3. Хостинг

Подойдёт любой статический хостинг с HTTPS:

| Сервис | Как задеплоить |
|---|---|
| **Cloudflare Pages** | pages.dev → «Create project» → «Direct upload» → перетащить папку `dist/` |
| **Netlify** | netlify.com → «Add new site» → «Deploy manually» → перетащить `dist/` |
| **Vercel** | `npx vercel deploy dist --prod` или drag-and-drop в dashboard |
| **GitHub Pages** | залить содержимое `dist/` в ветку `gh-pages` или в `/docs` |
| **Свой сервер** | nginx + Let's Encrypt, отдать `dist/` как корень сайта |

Получите URL вида `https://mygame.pages.dev`.

**Настройки хостинга:**
- `base: './'` в vite.config уже выставлен — билд работает из любого подкаталога;
- для `index.html` желателен короткий `Cache-Control` (например `max-age=300`) — Telegram webview агрессивно кеширует, иначе обновления до игроков доходят с задержкой.

**Локальный тест в настоящем Telegram** (без боевого деплоя):

```bash
npm run dev:tma        # в отдельном терминале
ngrok http 3000        # получите https://xxxx.ngrok-free.app
```

Этот временный URL можно вписать в бота (шаг 5), потестировать и заменить на постоянный.

## 4. Создание бота (@BotFather)

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя бота (видно в чате) и username, оканчивающийся на `bot`, например `my_crystal_bot`.
3. Получите **токен бота**. Клиенту он не нужен, но сохраните — он понадобится для платежей Stars, рассылок и любого бэкенда.

Дополнительно настройте профиль через `/mybots` → ваш бот → `Edit Bot`:

- `/setuserpic` — аватар бота;
- `/setabouttext`, `/setdescription` — тексты в профиле.

## 5. Создание Mini App (@BotFather)

```
/newapp
→ выбрать бота
→ название приложения (отображается в шапке мини-аппа)
→ описание
→ обложка 640×360 (можно взять готовый скрин из store_shots/)
→ демо-гифка (опционально; можно вырезать из роликов store_video/)
→ URL веб-приложения: https://mygame.pages.dev/
→ короткое имя (латиница), например: crystal
```

BotFather выдаст прямую ссылку:

```
https://t.me/my_crystal_bot/crystal
```

Эта ссылка и есть вход в игру — по ней приложение открывается внутри Telegram с авторизацией, CloudStorage и `addToHomeScreen`.

**Кнопка запуска в чате с ботом** (чтобы игроку не нужна была ссылка):

```bash
# заполнить в .env.tma: TG_BOT_TOKEN (от @BotFather) и TG_HOST_URL (адрес Pages)
npm run tg:menubutton
```

Скрипт `set_menu_button.mjs` вызывает Bot API `setChatMenuButton` — у всех пользователей рядом с полем ввода появится кнопка «🎮 Играть». Альтернатива руками: `/mybots` → бот → `Bot Settings` → `Menu Button`.

**Нюанс:** ярлык `addToHomeScreen` на части клиентов открывает чат с ботом, а не сам апп — это ограничение Telegram. Menu Button как раз покрывает этот случай: из чата игра запускается одним тапом.

## 6. Привязка ссылки к игре

В `.env.tma` пропишите диплинк — он копируется кнопкой «Поделиться»:

```env
VITE_TG_APP_URL=https://t.me/my_crystal_bot/crystal?startapp=invite
```

Параметр `startapp=invite` приходит в игру как `Telegram.WebApp.initDataUnsafe.start_param` — сейчас не используется, но это основа для реферальных бонусов («пригласи друга — обоим монеты»).

Пересоберите и задеплоите:

```bash
npm run build:tma
# залить содержимое dist/ на хостинг
```

## 7. Реклама (Adsgram)

У Telegram нет собственной рекламы для мини-аппов — используется сторонняя сеть, самая распространённая для TMA — Adsgram. Альтернативы: Monetag, TADS.

### Регистрация и создание блока

1. Зайдите на [adsgram.ai](https://adsgram.ai) → раздел **Publisher** (владелец приложения).
2. Добавьте приложение: укажите домен хостинга (`https://mygame.pages.dev`) и/или ссылку на бота.
3. Создайте рекламный блок формата **Rewarded Video** — получите `blockId` (вида `12345` или `reward-12345`).
4. Выплаты Adsgram производит в крипте (TON/USDT) или по договору.

### Подключение в проекте

В `.env.tma`:

```env
VITE_ADSGRAM_BLOCK_ID=12345
```

Пересоберите: `npm run build:tma` → деплой.

### Как это работает в коде

Адаптер `src/services/platform/tma.ts` при `init()` вызывает `Adsgram.init({ blockId })` и дальше:

- **Rewarded** (крутить колесо, буст ×2, сундуки): `adController.show()` — награда начисляется только при `result.done === true` (ролик досмотрен до конца);
- **Interstitial** (межстраничная реклама в паузах игры): тот же `show()` — по закрытию игра продолжается.

Нюансы:

- Один blockId используется для обоих форматов. Если хотите раздельную статистику/форматы — создайте в Adsgram второй блок и расширьте адаптер (два контроллера, второй env, например `VITE_ADSGRAM_INT_ID`).
- Если `VITE_ADSGRAM_BLOCK_ID` не задан — реклама эмулируется (награда выдаётся без показа). На локалке это удобно, в проде обязательно задайте blockId.
- Adsgram показывает рекламу только внутри реального Telegram-клиента; в браузере показов не будет.

## 7.5 Аналитика

У Telegram нет встроенной аналитики мини-аппов — подключены три системы, все опциональны и не ломают игру без ключей.

### PostHog (основная, устойчива к VPN)

1. [posthog.com](https://posthog.com) → Sign up → выберите **EU cloud** → Project → скопируйте **Project API key**.
2. В `.env.tma`:
   ```env
   VITE_POSTHOG_KEY=<project api key>
   VITE_POSTHOG_HOST=https://eu.i.posthog.com
   ```
3. Те же переменные — в **Settings → Variables → Actions** для CI (в `deploy.yml` уже проброшены).

Покрывает игроков, у которых WebView идёт через VPN (в отличие от `mc.yandex.ru`). События `session_start`, `prestige_win`, `rewarded_ad_watched` улетают через `capture`, пользователи идентифицируются как `tg_<user_id>`. Бесплатный тариф — 1 млн событий/мес + session replay + feature flags.

### Яндекс.Метрика (визиты, вебвизор — без VPN)

### Яндекс.Метрика (основная)

1. [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик**, URL = адрес хостинга (`https://shakalniy.github.io/Idle_clicker/`). В настройках счётчика включите **Вебвизор, карта скроллинга, аналитика форм**.
2. В `.env.tma`:
   ```env
   VITE_YM_COUNTER_ID=<номер счётчика>
   ```
3. Ту же переменную — в **Settings → Variables → Actions** для CI (в `deploy.yml` уже проброшена).

Что видно в дашборде: визиты/уники/удержание, карта кликов и вебвизор, источники трафика. Кастомные события игры (`session_start`, `prestige_win`, `rewarded_ad_watched`) шлются как цели через `reachGoal` — смотрите отчёт «Конверсии».

### Telemetree (резервная, ⚠️ сервис нестабилен)

SDK оставлен в сборке, но по состоянию на конец 2025 г. бэкенд Telemetree отдаёт 503 на авторизацию, репозиторий не коммитится с июня 2025 — сервис фактически заброшен. Если воскреснут:

```env
VITE_TELEMETREE_PROJECT_ID=<project id>
VITE_TELEMETREE_API_KEY=<api key>
```

События пойдут в обе системы одновременно, если заданы обе пары переменных — `trackEvent` рассылает в оба трекера.

## 8. Чеклист перед запуском

- [ ] `dist/` задеплоен по HTTPS, `https://mygame.pages.dev` открывается в браузере
- [ ] `npm run build:tma` собран с заполненным `.env.tma`
- [ ] В BotFather создан Mini App, ссылка `t.me/bot/app` открывает игру
- [ ] На телефоне: игра разворачивается на весь экран, свайп вниз не закрывает апп
- [ ] Сейв переживает закрытие/переоткрытие (CloudStorage)
- [ ] «Поделиться» копирует ссылку `t.me/...`
- [ ] Rewarded-реклама реально показывает ролик (с заданным blockId)
- [ ] Меню-лишних пунктов нет: «Лидерборд» и «Магазин» в TMA скрыты (платежи — только через бэкенд)

## 9. Чего нет без бэкенда

- **Платежи Telegram Stars.** Инвойс создаётся только серверной стороной: бот (по токену) вызывает Bot API `createInvoiceLink`, клиент открывает ссылку через `webApp.openInvoice(url)`. Нужен минимальный бэкенд (Vercel/Cloudflare Function хватит). Пока `payments: false` и магазин скрыт.
- **Серверный лидерборд / мультиплеер.** В TMA нет встроенных таблиц рекордов — только свой бэкенд (Bot API + БД).
- **Уведомления игрокам** («ваша шахта накопила монеты») — Bot API `sendMessage`, тоже бэкенд.

## 10. Траблушутинг

| Симптом | Причина / решение |
|---|---|
| Белый экран в Telegram | Проверьте HTTPS и что URL в BotFather оканчивается на `/`; откройте URL в браузере — если там ошибка, чините деплой |
| Старая версия после деплоя | Кеш webview — укоротите `Cache-Control` для `index.html`, добавьте `?v=2` к URL в боте |
| Реклама не показывается | Нет `VITE_ADSGRAM_BLOCK_ID`, блок не активирован в Adsgram, либо вы тестируете в браузере (Adsgram работает только внутри Telegram) |
| Сейв не сохраняется между устройствами | CloudStorage ограничен ~4096 байтами на ключ — при превышении пишется только localStorage (смотрите варнинг в консоли) |
| Свайп вниз сворачивает игру | Старый клиент Telegram без `disableVerticalSwipes` — обновите приложение |
| Проверить, что игра реально в TMA | В браузере адаптер работает в эмуляции — реклама мгновенная, CloudStorage не сохраняет между устройствами |

## 11. Рутина обновления

```bash
# правки кода → сборка → деплой → ссылка в боте та же
npm run build:tma
# залить dist/ на хостинг
```

Версия в кеше Telegram подхватится по мере обновления `index.html`; при проблемах — параметр `?v=N` в URL приложения в BotFather.
