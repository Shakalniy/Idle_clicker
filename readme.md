# 💎 Gem Miner Idle — Шаблон веб-игры для платформы Яндекс Игры

Полнофункциональный прототип браузерного кликера (Idle Clicker) с пассивным доходом, цепочкой предприятий, системой престижа (эволюцией кристалла) и монетизацией через Яндекс SDK.

Проект разработан на базе современного веб-стека без тяжелых движков, компилируется в бандл ~1.5 МБ (gzip ~400 КБ) и оптимизирован для мобильных и десктопных браузеров.

---

## 🛠 Технологический стек

* **Ядро движка:** [Phaser 4](https://phaser.io/) (v4.2+) — быстрый рендерер на WebGL / Canvas со встроенным аудиомикшером, твинами и системой частиц.
* **Язык разработки:** TypeScript 6 — строгая типизация состояния игры и контрактов SDK.
* **Сборщик:** [Vite 8](https://vitejs.dev/) — мгновенный HMR (горячая перезагрузка), оптимизация ассетов и относительные пути (`base: './'`) для корректного запуска в iframe Яндекса.
* **Платформенный слой:** Yandex Games SDK v2 — облачные сохранения, реклама с вознаграждением (Rewarded Video), подготовка к таблицам лидеров.

## 🚀 Что уже реализовано

### 1. Архитектура и интеграция с платформой
* **Адаптивный Canvas (720 × 1280):** Игра использует режим `Phaser.Scale.FIT` с автоцентрированием `CENTER_BOTH`. Игра пропорционально масштабируется как на смартфонах с любой диагональю, так и в окне десктопного браузера.
* **Мультиплатформенный слой `services/platform/`:**
  * Игра работает с платформой только через интерфейс `IPlatform` (реклама, сейвы, лидерборд, платежи, авторизация). Адаптер выбирается фабрикой `getPlatform()` по режиму сборки (`vite build --mode yandex|web`).
  * `YandexPlatform` — полная интеграция с Яндекс.Играми: `ysdk`, `getPlayer({ scopes: true })`, облачные сейвы с приоритетом над localStorage. На `localhost` без SDK — эмуляция (dev-режим).
  * `VkPlatform` — VK Игры через `vk-bridge`: реклама `VKWebAppShowNativeAds`, облачные сейвы `VKWebAppStorageGet/Set`, нативный лидерборд `VKWebAppShowLeaderBoardBox`, платежи голосами `VKWebAppShowOrderBox`, «В избранное» как аналог шортката.
  * `TmaPlatform` — Telegram Mini Apps: `telegram-web-app.js`, облачные сейвы `CloudStorage`, реклама через Adsgram (`VITE_ADSGRAM_BLOCK_ID` в `.env.tma`), ярлык `addToHomeScreen`. Лидерборда и платежей нет — Stars-инвойсы требуют бот-бэкенда.
  * `WebPlatform` — универсальный веб-адаптер: сейвы в `localStorage`, реклама эмулируется, без платежей/лидерборда. База для порталов (CrazyGames, Telegram) — для новой платформы добавьте адаптер, режим сборки и SDK-скрипт в `vite.config.ts`.
  * Флаги `capabilities` говорят UI, какие фичи доступны (шорткат, авторизация и т.п.).
* **Безопасная монетизация:** Начисление монет и бонусов происходит строго внутри события `onRewarded`, что защищает от накруток при преждевременном закрытии рекламы.

### 2. Игровая экономика и механики
* **Центральный интерактивный кристалл:**
  * Гранёный спрайт кристалла (генерируется процедурно через `Graphics.generateTexture()` — 50 вариантов расцветки по рангам, без внешних ассетов).
  * Анимация сжатия и пружинящего отскока (*Squash & Stretch*) при тапе через твины Phaser.
  * Фонтан частиц при каждом клике: золотые монетки + осколки цвета текущего ранга кристалла.
  * Разлетающиеся всплывающие индикаторы дохода (`+N`) со случайным смещением по оси X.
  * Прокачка «Силы клика» по экспоненциальной формуле:
    $$\text{Cost} = \lfloor 10 \times 1.25^{\text{level} - 1} \rfloor$$
* **Цепочка из 5 добывающих предприятий:**
  * ⛏️ **Шахтер:** $+1$ монета/сек (базовая цена: 20)
  * 🚜 **Буровая машина:** $+6$ монет/сек (базовая цена: 120)
  * 🏭 **Обогатительная фабрика:** $+35$ монет/сек (базовая цена: 750)
  * 🚂 **Шахтный поезд:** $+220$ монет/сек (базовая цена: 4 500)
  * ⚡ **Квантовый луч:** $+1\,500$ монет/сек (базовая цена: 28 000)
  * Динамический расчет цен зданий:
    $$\text{Cost}(N) = \lfloor \text{BaseCost} \times 1.15^N \rfloor$$
  * Визуальная индикация доступности: кнопки автоматически меняют цвет (синий — доступно, темно-серый — недостаточно монет).
* **Система престижа (Эволюция через босфайт):**
  * 50 рангов кристаллов, выстроенных по реальной мировой ценности минералов: Кальцит ➔ Гипс ➔ Кварц ➔ … ➔ Жадеит ➔ Рубин ➔ … ➔ Розовый/Голубой/Красный алмаз ➔ Тёмный Алмаз ➔ Небесный Алмаз ➔ Звёздный Алмаз.
  * Смена визуала: изменение цвета кнопки, обводки, свечения и иконки.
  * Выбор 1 из 3 постоянных даров при перерождении (все масштабируются и сбалансированы):
    1. **Дар Мощи:** +25% к силе клика навсегда (стекится: ×1.25, ×1.5, ×1.75…).
    2. **Дар Процветания:** +10% ко всему пассивному доходу навсегда (мультипликатор).
    3. **Дар Бригады:** −7% к цене предприятий за дар (перемножается, потолок −70%).
* **Босфайт «Страж ранга»** (вместо простой покупки ранга):
  * Кнопка эволюции открывает бой: монеты — **входной билет** (`bossPaidTier` в сейве — поражения и ретраи бесплатны, вход не сгорает).
  * Босс — тёмная версия кристалла следующего ранга; HP = `сила клика × (55 + ранг×8)` — бой всегда проверяет реальную прокачку игрока.
  * 45 секунд, 3 жизни. Урон = `getClickPower()` со всеми множителями и критами + пассивный урон шахтёров (`cps × 0.12/с`, виден кирками, летящими в босса, и всплывающими цифрами).
  * Удары ⚠: маркер со сжимающимся кольцом-таймером (1.1 с) — тап = парирование +×4 урона, промах = −1 жизнь.
  * **7 архетипов** по рангам (`BOSS_ARCHETYPES`): Страж → Охранник (щит 🛡 3с вкл / 9с выкл) → Сокрушитель (+точки 🎯 ×3) → Живучий (+реген при простое) → Латник (броня: тапы ×0.35) → Берсерк (+ярость <50% HP) → Владыка (всё + двойные удары). Каждый 10-й ранг — эпохальный 👑-титул.
  * Визуал: вход босса с грохотом снизу, дыхание/покачивание контейнера, трещины по фазам HP (66%/33% — раскалённые, движутся с кристаллом), краснение на <30% HP.
  * Экран победы: статистика (время, урон, жизни, парирования) + **перфект-бонус** +1 🔮 за бой без потерь → кнопка к выбору дара.
  * Поражение: ретрай бесплатен, «📺 +1 жизнь за рекламу» (rewarded-возрождение, 1 раз за бой), отступление без потерь.
* **Летающий бонус (Lucky Drop):**
  * Раз в 35–55 секунд через холст пролетает светящийся сундук (спрайт).
  * При клике открывается выбор: забрать стандартную награду или умножить её на $\times 5$ за просмотр видео.
* **Атмосфера сцены:** фоновые всплывающие пылинки (ambient particles) для глубины картинки.
* **Офлайн-доход:**
  * При перезапуске игра вычисляет дельту времени от `lastSaveTime` (с лимитом до 8 часов).
  * Диалоговое окно предлагает забрать накопленные шахтерами ресурсы или удвоить их за просмотр ролика.
* **Система заданий (контракты):**
  * Панель внизу экрана с текущим заданием, прогрессом и кнопкой награды.
  * 10 заданий на клики, найм, заработок и первую эволюцию; прогресс считается по накопленной статистике (`stats`).
* **Параллельная прокачка кирки:** «⭐ Легендарная кирка» — отдельная ветка, +25% к силе клика за уровень (цена `500 × 1.4^ур`), множит всё: клики, автокликер, награды сундуков.
* **Клик масштабируется с экономикой:** каждый уровень «Удара кирки» добавляет +0.1% от пассивного `/сек` к каждому тапу — при 6 тапах/сек прокачка клика остаётся сопоставимо выгодной со зданиями на любой стадии игры.
* **Дар Мощи усиливает кирку:** перк престижа даёт +3 к силе клика **и +3 к каждому уровню** «Удара кирки» (ретроактивно: сила = `уровень × (1 + clickBonus)`).
* **Комбо-тапы:** серия кликов с паузой < 1 с растит множитель клика до ×3 (до ×5 на ранге Топаз).
* **Золотой шар (Жадеит):** раз в 150–270 с пролетает золотая сфера — клик включает ×7 к силе клика на 10 секунд (на ранге Жадеит — ×10 на 15 с).
* **Ежедневные награды:** стрик входов до 7 дней, награда `max(база, cps × 180)` масштабируется с прогрессом игрока.
* **Форматирование чисел:** компактное отображение `1.2K / 3.4M / 7B` для всех сумм и цен.
* **Защита от автокликеров:** анализ окна последних 16 кликов — подозрение при >25 кликов/с или при роботизированно ровных интервалах (σ < 3 мс) в одну точку. Штраф: награды кликов ×0.1 на 10 секунд с предупреждением на экране.
* **Механики рангов кристалла (кумулятивные, на 13 рангах из 50):**
  * 🟠 Агат — критические клики: 5% шанс ×10.
  * ⚫ Оникс — автокликер +2 клика/сек.
  * ⬛ Обсидиан — автокликер +5 кликов/сек.
  * 🔮 Аметист — офлайн-доход ×2.
  * ❤️ Гранат — награды сундуков ×2.
  * 🌙 Лунный камень — офлайн-кап 16 ч вместо 8 ч.
  * 🔶 Топаз — потолок комбо ×5 вместо ×3.
  * 🌈 Опал — шанс крита вырос до 10%.
  * 🟩 Жадеит — золотой шар даёт ×10 на 15 с.
  * 🪷 Падпараджа — весь доход ×1.5.
  * 🖤 Тёмный Алмаз — весь доход ×2 (итого ×3 с Падпараджей).
  * ✨ Небесный Алмаз — автокликер +10 кликов/сек.
  * ⭐ Звёздный Алмаз — комбо не сгорает при паузах.
* **Менеджеры:** кнопка 👔 в шапке — найм менеджера за `baseCost × 25` удваивает доход здания навсегда (не сгорает при эволюции).
* **Коллекция артефактов:** 30% шанс дропа с золотого сундука — 6 предметов с множителями дохода и силы клика; баннер с бонусом при дропе, тултип по наведению на иконку в строке коллекции.
* **Событие дня «Жила золота»:** 45% шанс каждый новый день — весь доход ×3 (индикатор в шапке).
* **Скины кристалла:** кнопка 🎨 — 6 скинов за монеты; каждый тонирует сам кристалл (`setTint`) и меняет цвет/силу свечения. «Призма» (2.5M) — анимированная: кристалл переливается всеми цветами радуги в реальном времени.

### 3. Звуковая система
* **Обход политики Web Audio Autoplay:** Звуковой контекст мягко разблокируется при первом клике игрока по экрану.
* **Отсечение звуков клика:** Повторный клик прерывает предыдущий экземпляр звука через `stopByKey('click')`, исключая эффект «звуковой каши».
* **Питч-шифтинг:** Каждый клик имеет легкий случайный разброс высоты тона (`detune: [-150, 150]`), снижающий утомляемость слуха.
* **Тумблер звука:** Кнопка 🔊 / 🔇 в правом верхнем углу для полного глушения игры.
* **Боевая музыка:** опциональный `assets/boss.mp3` (луп) на время босфайта; без файла — фоновая тема автоматически разгоняется (`rate ×1.18`, `detune +250`) в «боевой режим».
* **Процедурные SFX босфайта:** удары, парирования, получение урона, щит, слабые точки, победа и поражение синтезируются через Web Audio API (осцилляторы) — файлов не требуется, громкость уважает настройку и мьют.
* **Экран загрузки:** полоса прогресса в BootScene пока грузятся ассеты и генерируются текстуры.

## 💻 Установка и локальный запуск

1. **Клонирование / открытие папки:**
   ```bash
   cd my-yandex-game
   ```

2. **Установка зависимостей:**
   ```bash
   npm install
   ```

3. **Запуск сервера разработки:**
   ```bash
   npm run dev
   ```
   *Игра откроется по адресу `http://127.0.0.1:3000/`.*

---

## 📦 Сборка и публикация на Яндекс Игры

1. Соберите production-бандл:
   ```bash
   npm run build
   ```
2. Откройте появившуюся папку `dist/`.
3. Выделите все файлы внутри `dist/` (`index.html`, папку `assets/`) и упакуйте их напрямую в **ZIP-архив**.
   > *Важно: `index.html` должен лежать в корне архива, а не внутри подпапки.*
4. Перейдите в [Консоль разработчика Яндекс Игр](https://yandex.ru/dev/games/console/), создайте черновик и загрузите архив во вкладке **«Исходный код»**.
